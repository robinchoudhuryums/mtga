REGRESSION RISKS:
- `make refresh` runs the FULL chain including the slow full-pool builds. Someone who previously hand-ran only `build_gallery.py` now pays the whole cost unless they deliberately follow `/refresh`'s step list, which is retained for exactly that. Documented in the help line and the skill.
- `verify_ingest.py --exact` applied to a deck-dump or crafted-cards paste will report false failures by design, since those are lower bounds. Mitigated by the flag help, the skill text, and the report itself naming which reading it used.
- The verifier's `mana=None` parameter was genuinely ambiguous in the first draft — `mana_names()` returns `None` for "file absent", so the same value also meant "not supplied", and `main()` only worked by calling `mana_names()` twice. Fixed with a distinct `_UNSET` sentinel before landing; found by a test, not by review.
- No interface changed. `verify_ingest.py` is new and read-only — it writes nothing, so it cannot damage data even when wrong. `import_arena.parse` and `lib.owned_qty` are imported, not modified.
- The Makefile's existing targets (`app`, `check`, `test-units`, `verify`, `clean-venv`) are untouched; `refresh` was added to `.PHONY`.
