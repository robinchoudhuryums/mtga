# Flex — measured and parked. See: deck.py flex 48
#~ +Dauntless Scrapbot | CRAFT (Uncommon) — {3} 3/1 Robot: ETB exiles each opponent's graveyard and creates a Lander token (ramp + an artifact token). Genuinely reasonable, and it MEASURED as a non-upgrade in every configuration tried: paying for it by cutting cheap bodies (Aerial Doombot, Viv Vision) dropped card advantage 2 -> 1, and paying with Untimely Malfunction dropped interaction 10 -> 9. Not rejected on fit — the deck simply has no slot whose loss is cheaper than the gain.
#~ +Spider-Bot | CRAFT (Common) — {2} 2/1 reach Robot with a land-smoothing ETB. Same finding as above; it is the marginal card in a 36-slot list that is already tight.
#~ -Mm'menon, Uthros Exile | +Adaptive Automaton | CRAFT (Rare) — THE PLANNED RE-ADD, parked only on wildcard cost. Adaptive Automaton is one of only FIVE choose-a-type anthems in Standard ("as this enters, choose a creature type; other creatures you control of the chosen type get +1/+1") and this deck already runs three of the other four; the fifth is Oko, which is U/G and uncastable here. There is no cheaper substitute because there is no other card that does this — a pool sweep by EFFECT SHAPE (not the type name, see K-13) returns exactly those five. It is also a {3} ARTIFACT creature, so it is a body the other lords pump and it feeds Ravenous Robots. Mm'menon holds the slot at UNCOMMON: it flies and puts a +1/+1 counter on a creature per artifact entering, which is real in a deck that floods artifacts but is a per-turn trickle where the Automaton is a board-wide multiplier. Measured as a wash on every axis the vector can see (interaction 10, card advantage 2, protection 3, avg MV 3.19, 13 early drops) — READ THAT AS THE MODEL BEING BLIND, not as parity: role_tally has no anthem axis, so it scores a lord and a vanilla body identically. Swap back the moment a Rare wildcard is free.
